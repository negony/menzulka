# Сторонние компоненты и лицензии

Приложение «Мензулка» распространяется под лицензией **MIT** (см. `LICENSE`).

Ниже — компоненты, которые используются в сборке, и их лицензии. Здесь нет
компонентов под GPL/AGPL: для чтения DWG мы сознательно не используем LibreDWG
(GPLv3) и не поставляем проприетарные библиотеки Autodesk/ODA.

## Нативный слой DWG → DXF

### acadrust — MPL-2.0

- **Что это:** независимая реализация чтения и записи DWG/DXF на Rust.
- **Версия:** `=0.6.8` (закреплена в `native/Cargo.toml`).
- **Лицензия:** Mozilla Public License 2.0 — <https://www.mozilla.org/MPL/2.0/>.
- **Источник:** <https://github.com/hakanaktt/acadrust>, пакет: <https://crates.io/crates/acadrust>.
- **Как используется:** как неизменённая библиотека (crate) при сборке
  `native/menzulka_cad`. Файлы acadrust не изменяются; если появится
  необходимость в патче, изменённые файлы будут опубликованы под MPL-2.0.
- **Обязательства MPL-2.0:** исходный код компонента доступен по ссылке выше;
  уведомление о лицензии сохраняется в этой поставке. MPL-2.0 не требует
  открывать код самого приложения «Мензулка».

## Прочие компоненты нативного слоя

Все зависимости Rust перечислены в `native/Cargo.lock` и проверяются
`cargo deny check licenses` с разрешённым списком разрешительных лицензий
(MIT, Apache-2.0, MPL-2.0, BSD-2/3, ISC, Zlib, Unicode-3.0, CC0, Unlicense).

## Flutter/Dart-пакеты

Зависимости приложения перечислены в `pubspec.yaml`/`pubspec.lock`; это
популярные пакеты с лицензиями MIT/BSD/Apache-2.0. Полные тексты лицензий
пакетов Flutter доступны в приложении через стандартный реестр лицензий
(`showLicensePage`).

## Не входит в поставку

- **ODA File Converter** — бесплатная утилита конвертации, устанавливается
  пользователем самостоятельно; в APK/установщик не входит и не
  распространяется. Упоминается только как запасной способ для Windows
  (<https://www.opendesign.com/guestfiles/oda_file_converter>).
- **Autodesk AutoCAD / DWG TrueView** — не входят в поставку.
- **LibreDWG** (GPLv3) — не используется.
